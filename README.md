# Photo Gallery App

This is a simple photo gallery app built with **React** that allows users to search and view high-quality images from Unsplash. The app fetches and displays images based on user queries and provides a seamless experience to explore a wide range of photos.

## Features

- **Search functionality**: Users can search for photos using the search bar.
- **Dynamic photo display**: Images are loaded dynamically as you search, showing a gallery of images based on your query.
- **Loading state**: A loading indicator is shown while the images are being fetched.
- **Responsive UI**: The photo grid adjusts to different screen sizes for a smooth user experience.
